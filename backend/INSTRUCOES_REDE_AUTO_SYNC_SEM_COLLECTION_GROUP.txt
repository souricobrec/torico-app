TORICO - Correção sync automático REDE sem collectionGroup

Arquivo:
- server.js atualizado

Correção aplicada:
- A versão anterior ainda usava collectionGroup('integration_status'), e o Firestore exigiu índice COLLECTION_GROUP_ASC.
- Esta versão remove o collectionGroup.
- Agora a rota lista users e, para cada usuário, lê diretamente:
  users/{uid}/integration_status/rede
- Isso evita criar índice agora e funciona para o MVP/baixo volume.

Teste local:
node --check server.js

git commit -m "Remove collectionGroup do sync automatico REDE"
