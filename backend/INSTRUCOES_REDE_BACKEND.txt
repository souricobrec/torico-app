TORICO - Backend REDE Gestão de Vendas

Arquivos:
- server.js atualizado com base da integração REDE.

O que foi adicionado:
- Variáveis REDE no backend.
- Health com bloco rede.
- Funções para gerar token REDE.
- Funções para consultar /merchant-statement/v1/sales.
- Rota protegida:
  GET /integrations/rede/sales-test

Importante:
- A rota /integrations/rede/sales-test NÃO grava vendas no Firestore.
- Ela apenas gera token, consulta a API REDE, normaliza vendas APPROVED de POS/PDV e retorna JSON.
- A rota exige header x-torico-dev-key.

Variáveis necessárias no Cloud Run:
REDE_CLIENT_ID
REDE_CLIENT_SECRET
REDE_API_BASE_URL=https://rl7-sandbox-api.useredecloud.com.br
REDE_DEFAULT_PARENT_COMPANY_NUMBER=13381369
REDE_DEFAULT_SUBSIDIARIES=13381369
REDE_DEFAULT_SALES_LOOKBACK_DAYS=20
REDE_ALLOWED_CAPTURE_TYPES=POS,PDV

Teste local obrigatório:
cd C:\vendaon\backend
node --check server.js

Teste da rota:
Invoke-RestMethod `
  -Method Get `
  -Uri "https://torico-backend-16783123127.us-central1.run.app/integrations/rede/sales-test" `
