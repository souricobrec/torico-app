TORICO - Sincronização automática REDE

Arquivo:
- server.js atualizado

O que foi adicionado:
- Rota POST /integrations/rede/sync-connected-users
- Protegida por x-torico-dev-key
- Busca usuários com users/{uid}/integration_status/rede status=connected usando collectionGroup
- Sincroniza CREDIT e DEBIT por usuário conectado
- dryRun=true por padrão
- dryRun=false salva no Firestore com saveSale()
- Mantém idempotência por externalId
- Usa a configuração salva em users/{uid}/integrations/rede
- Atualiza daily_totals automaticamente pela função saveSale existente
- Adiciona a rota no /health em health.rede.syncConnectedUsersRoute

Teste local:
node --check server.js

Commit sugerido:
git add server.js INSTRUCOES_REDE_AUTO_SYNC.txt
git commit -m "Adiciona sincronizacao automatica REDE"
git push origin visual-pre-lojas

Deploy Cloud Run:
gcloud run deploy torico-backend --source . --region us-central1 --allow-unauthenticated
